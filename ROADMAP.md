# Seven-day development roadmap

Day 1: Release the first version and gather feedback from three users.
Day 2: Add more document rows and editable titles.
Day 3: Add separate father/mother name and address comparison.
Day 4: Add user-created application checklist templates with source links and review dates.
Day 5: Improve keyboard accessibility and screen-reader feedback.
Day 6: Add local document parsing with explicit user consent; keep manual review.
Day 7: Review bugs, record a demo and publish v1.1 release notes.

Commit actual improvements with descriptive messages. Keep private identity details, backups and document scans out of GitHub.
